## 本地可重复检查

```sh
npm test
npm run build
```

浏览器扩展加载后的真实运行记录应包含浏览器名称与版本、扩展构建 SHA、测试页来源、实际请求、发现结果、NAS 任务 ID、任务终态、最终 MP4 的 ffprobe 摘要和播放检查。不得记录 Cookie 或完整敏感请求头。
